# Sources

## Template content
Everything in `template/` and `library/` is original to this repo, generalized from the FitTrack+ project's
setup. The `.taskmaster/` layout and task fields follow Task Master's conventions
(https://github.com/eyaltoledano/claude-task-master) so a project can adopt that tool later; no code is copied
from it.

## External skills
None are bundled in v1.0.0. BOOTSTRAP may adopt up to 5 per project after vetting; each project records them in
its own `.claude/SOURCES.md` (name, URL, license, commit or date, why).

## Vetting rules (for anything added here later)
Small and single-purpose; permissive license; maintained in the last year; markdown only; no network calls,
credential access or remote scripts; no instructions to ignore other rules; read in full before adding.
